# 评分细则（scoring_rules.md）

## 评分总览（100 分制）

```
放量质量(30) + 缩量质量(20) + 横盘质量(25) + 趋势量能(15) + 加分信号(10) = 100
```

## 一、放量质量（30 分）

| 因子 | 条件 | 得分 |
|:-----|:-----|:----:|
| 放量倍数 | 1.5 ≤ 量比 < 2 | 8 |
| | 2 ≤ 量比 < 3 | 12 |
| | 量比 ≥ 3 | 15 |
| 拉升幅度 | 达标线 | 5 |
| | 每超 1 个百分点 | +2 |
| | 上限 | 10 |
| 60 日新高 | 放量日 high 创前 60 日新高 | +5 |

> 拉升幅度示例（主板）：涨幅 5% → 5 分；7% → 9 分；≥7.5% → 10 分封顶

## 二、缩量质量（20 分）

| 因子 | 条件 | 得分 |
|:-----|:-----|:----:|
| 缩量深度 | < 30% | 10 |
| | 30%~50% | 8 |
| | 50%~70% | 5 |
| | > 70% | 3 |
| 缩量天数 | 2~3 天 | 3 |
| | 4~6 天 | 5 |
| | 7~8 天 | 4 |
| | 其他 | 0 |

> 缩量深度 = 缩量段均量 / 放量日量。缩得越深，说明抛压越轻、筹码锁定越好。

## 三、横盘质量（25 分）

| 因子 | 条件 | 得分 |
|:-----|:-----|:----:|
| 振幅 | ≤ 5% | 10 |
| | 5%~10% | 7 |
| 横盘位置 | 主体在上半部（收盘均值 ≥ 锚点K线中点） | 8 |
| | 中部 | 5 |
| | 下半部 | 3 |
| 回调深度 | 回撤 ≤ 1/2 拉升幅度 | 5 |
| | 1/2 ~ 2/3 | 2 |
| | > 2/3 | 0 |
| 低点抬高 | 后半段最低 > 前半段最低 | +2 |

> 回调深度 = (放量日收盘 - 横盘期最低) / (放量日收盘 - 前日收盘)。回调越浅越强势。

## 四、趋势与量能（15 分）

| 因子 | 条件 | 得分 |
|:-----|:-----|:----:|
| 平台突破 | 放量日创 60 日新高 | +8 |
| 均线支撑 | 最新收盘 > MA10 且 > MA20 | +4 |
| 量能均线多头 | 5 日均量 > 10 日均量 | +3 |

## 五、加分信号（10 分）

| 因子 | 条件 | 得分 |
|:-----|:-----|:----:|
| 量价齐升 | 窗口内连续 3 日量升价升 | +5 |
| 量缩价跌 | 窗口内连续 3 日量缩价跌 | +5 |

## 分层与预警

| 总分 | 分层 | 建议 |
|:----:|:-----|:-----|
| ≥ 80 | 强势形态 | 形态质量高，优先关注 |
| 60~79 | 标准形态 | 形态成立，需结合其他维度 |
| < 60 | 关注形态 | 边缘命中，谨慎对待 |

**背离预警**（不扣分，独立标记）：
- 横盘期出现：成交量 > 前5日均量 × 1.5 且当日涨幅 < 1% → 放量滞涨
- 含义：横盘末端放量却拉不动价格，主力可能借横盘出货 → 排序自动降级

## 评分示例

标准命中（茅台 2026-07 实测）：
```
放量质量 17.0/30（量比2.3→12 + 拉升7%→5 + 新高✗→0）
缩量质量  5.0/20（深度51%→5 + 天数9→0）
横盘质量 17.0/25（振幅6.4%→7 + 位置upper→8 + 回调→2 + 低点✗→0）
趋势量能  4.0/15（新高✗ + 均线✓→4 + 量能✗）
加分信号 10.0/10（齐升✓ + 缩跌✓）
总分 53.0 → 关注形态 + 背离预警
```
