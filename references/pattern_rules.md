# 形态规则详解 V3.0（pattern_rules.md）

## V3.0 新增：阶段3 四种形态变体

阶段1（放量拉升）和阶段2（缩量计算）为所有变体共享。阶段3 按优先级 D>C>B>A 判定：

| 变体 | 标签 | 缩量要求 | 核心条件 |
|:-----|:-----|:--------:|:---------|
| D | 突破延续 | 不强制 | 累计涨幅≥3%, ≥60%阳线, 未跌破开盘价, 振幅≤15% |
| C | 回踩确认 | ≥2日 | 振幅≤10%, 至少1日low≤anchor.high×1.02, 之后close>anchor.high |
| B | 高位平台 | ≥2日 | 振幅≤10%, ≥60%日close>anchor.high, 均价>anchor.high |
| A | 标准横盘 | ≥2日 | 振幅≤10%, ≥60%日close∈[anchor.low, anchor.high] |

## 四阶段判定细节

### 阶段1：定位放量拉升日
- 遍历最近 `window` 根 K 线
- 涨幅 = (当日收盘 - 前日收盘) / 前日收盘 × 100%
- 量比 = 当日量 / 前20日均量（不含当日）
- 同时满足 `涨幅 ≥ 阈值(板块)` 且 `量比 ≥ 1.5` → 候选放量日
- 多个候选 → 取**最近**（索引最大）为锚点
- 浮点容差 1e-9（边界值如恰好 5.0% 算命中）

### 阶段2：缩量确认
- 锚点日之后逐日扫描，统计最长连续缩量段（量 < 锚点日量）
- 最长段 ≥ 2 日 → 通过
- `shrink_days` = 最长段长度；`shrink_depth` = 该段均量 / 锚点日量

### 阶段3：横盘确认
- 锚点日后**所有**交易日（至窗口末）
- 振幅 = (最高 - 最低) / 最低 × 100% ≤ 10%
- 收盘价落在锚点日 [low, high] 区间内的占比 ≥ 60%
- 两条件同时满足 → 通过

### 阶段4：加分信号
- 窗口内任意连续 3 日：量递增且价递增 → 量价齐升 ✓
- 窗口内任意连续 3 日：量递减且价递减 → 量缩价跌 ✓
